Tungkol sa proyekto

Impormasyong mas madaling mahanap.

Ang Better Tanauan ay isang independent community project para sa Tanauan City, Batangas, na pinapanatili ni @zerozepol.

Layunin nitong pagsama-samahin ang public information at ituro ka sa mga opisyal na source. Hindi ito opisyal na LGU website at hindi pa nakarehistro o ineendorso ng BetterGov.

Framework ng portal

Sinusunod ang mga paksa ng BetterGov LGU guide: mga opisyal, budget, proyekto, ordinansa, at contact information. Reference ang service-first navigation ng BetterSolano. Inangkop mula sa BetterSolano static template ni Ramon Logan Jr.; binago ang branding, nilalaman, at directory behavior para sa LGU na ito.

Paano binuo ang directory

May source link at petsa ng pag-review ang bawat entry. Ang barangay listings ay pangalan at sakop na LGU lamang; hindi sila verified contact listings. Ang mga nawawala o magkakasalungat na detalye ay malinaw na minarkahan.

May kailangang itama?

Magbukas ng issue sa repository kasama ang pangalan ng entry, tamang impormasyon, at public source.
