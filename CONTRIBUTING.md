# Contributing

Use public government sources. Avoid personal private information. Keep a source URL and review date with each record. Explicitly mark historical records, unverified text and missing contact information. Never treat a procurement notice as proof of project completion or a provincial budget as a municipal budget. No speculative officials, phone numbers, budget figures or ordinances. Run `node --check src/app.js` and `node build.mjs`, then test relevant UI behavior before a PR.
